# Reminders for Windows v1.2.0

## What's new

- Choose an Apple-style interface in **Settings → General → Appearance →
  Interface style**. It includes colored sidebar icons, circular completion
  controls, priority marks, and a rounded details form. You can switch back to
  the original Windows interface, and both styles support light and dark themes.
- A new welcome screen introduces the app before iCloud setup. You can also
  try sample reminders without connecting an account.
- A short tour after your first successful sign-in explains lists, search,
  adding and editing reminders, completion, and sync. Skip it at any time or
  replay it from **Settings → About → Take the app tour**.
- Welcome and setup screens use matching cards, colors, and controls, with
  simpler text and layouts that adapt to smaller windows.

## Installing and updating

- **Intel/AMD PCs:** Download `Reminders-for-Windows-x64-Setup.exe`.
- **Windows on Arm:** Download `Reminders-for-Windows-arm64-Setup.exe`.
- **Portable:** Extract the matching ZIP completely and run `Reminders.exe`.
- **Microsoft Store:** Install from the [Store listing](https://apps.microsoft.com/detail/9PH6GW0M6G86).
  The attached MSIX files are unsigned submission packages for the publisher.
  The Store update becomes available after Microsoft certification and publication.

Installer users can select **Settings → About → Check for updates**. Updates
preserve cached reminders, queued edits, preferences, and saved sign-in.

## Validation

The release workflow runs backend, onboarding, UI-resource, updater, and
publishing checks; builds and packages x64 and ARM64; and checks packaged launch
on x64. The revised onboarding layout, the complete guided tour, native ARM64
launch, and live Apple-device sync still need device testing.
