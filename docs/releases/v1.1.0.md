# Reminders for Windows v1.1.0

## What's new

- Move an existing reminder to another list using the **List** field in its
  details pane. Moving a parent task brings its active subtasks along.
- Select **Add subtask** in a task's details to create a child in the same list.
  Subtasks appear directly below their parent. Use the arrow on the right to
  expand or collapse them.
- Keep your edits when switching tasks, changing lists or closing the window.
  The app prompts you to save, discard or keep editing. Saving changes only the
  fields you edited, preserving newer sync updates to other fields.
- Fix stale search and navigation results, duplicate sidebar actions, low
  contrast reminder metadata in light mode, and clipped compact task details.

## Installing and updating

- **Intel/AMD PCs** — Download `Reminders-for-Windows-x64-Setup.exe`.
- **Windows on Arm** — Download `Reminders-for-Windows-arm64-Setup.exe`.
- **Portable** — Extract the matching ZIP completely and run `Reminders.exe`.
- **Microsoft Store** — The MSIX files attached here are unsigned submission
  packages. Install through the Store listing for a Microsoft-signed package.

Installer users can select **Settings → About → Check for updates**. Updates
preserve cached reminders, queued edits, preferences and saved sign-in.

## Validation

The release workflow runs account-free backend and updater tests, builds and
packages x64 and ARM64, and checks packaged launch on x64. Subtask sync is covered
by tests with mocked iCloud responses. Live Apple-device sync and native ARM64
launch still need device testing.
