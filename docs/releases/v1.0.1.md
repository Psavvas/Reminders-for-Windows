# Reminders for Windows v1.0.1

## Fixes

- Renaming an iPhone-created reminder now preserves Apple's text edit history,
  preventing the old and new titles from being joined together. The same fix
  applies to notes, repeated edits, clearing text and Unicode characters.
- Completing a supported recurring reminder now creates its completed history
  from supported writable fields instead of copying incompatible native record
  metadata. The active reminder keeps its schedule and linked records.
- Empty repeat constraints encoded by Apple devices are recognized as a simple
  schedule. Nonempty custom constraints remain protected.
- Lost-response retries recover an already committed completion without creating
  duplicate history or advancing the repeat twice.

## Installing and updating

- Intel/AMD PCs: **Reminders-for-Windows-x64-Setup.exe**.
- Windows on Arm: **Reminders-for-Windows-arm64-Setup.exe**.
- Portable use: extract the matching ZIP completely and run `Reminders.exe`.
- The separate x64/ARM64 MSIX files are unsigned Microsoft Store submission
  packages. Use the Microsoft Store listing for a Store-signed installation.

Installer users can select **Settings → About → Check for updates**. Updates
preserve cached reminders, queued edits, preferences and saved sign-in.

If a title was already joined by an earlier version, rename it to the intended
text after updating. Existing rejected uploads stay queued for the next sync.

## Validation

896 account-free backend/authentication/scheduling/layout checks and 24 updater
checks pass locally. Synthetic native documents were also merged through Apple's
public text engine to verify replacement, clearing, Unicode and repeated edits.
The release pipeline validates both architectures, packaging and x64 packaged
launch. Live iPhone sync still needs confirmation; these checks do not establish
every Apple account or device scenario.
