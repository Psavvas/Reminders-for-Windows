# Reminders for Windows v1.0.0

## What's changed

- Refreshed setup, authentication, recovery and developer documentation. Removed
  obsolete interface screenshots, technology badges and the retired backend audit.
- Faster incremental sync, with a one-minute default interval. A rejected upload
  stays queued while unrelated tasks continue syncing; incomplete uploads are
  reported instead of announcing success.
- Create and edit daily, weekly, monthly and yearly repeats, including custom
  intervals. Completing a supported repeat advances the active reminder and
  retains its schedule. Windows/iPhone frequency mapping is corrected.
- Apple-hosted sign-in supports the verification methods Apple offers, then
  returns to the native app. Saved trust, cookies and session tokens support
  reopening without another verification while Apple accepts the session.
  Native SMS sign-in remains available.
- Settings now has General, Sync & storage, Account and About pages. Sign out,
  full cache reset and selective **Discard unsynced changes** recovery are
  available. Recovery removes selected local-only drafts or restores cloud-backed
  tasks without deleting iCloud records or clearing other cached tasks.
- Updated setup, task details and New reminder layouts; readable split panes and
  full-width details at either resize endpoint; themed title bars, corrected
  shell icons and animated sync notices over the content.
- Sidebar ordering persists. Update checks stay inside Settings. The Completed
  page no longer shows the completed-reminders switch.
- Existing iCloud tags remain visible and filterable. Tag editing and automatic
  tag repair are removed because native iPhone propagation could not be verified.
  Old queued tag writes are retired locally so ordinary edits can continue.

## Installing and updating

- Intel/AMD PCs: **Reminders-for-Windows-x64-Setup.exe**.
- Windows on Arm: **Reminders-for-Windows-arm64-Setup.exe**.
- Portable use: extract the matching ZIP completely and run `Reminders.exe`.
- **Reminders-for-Windows-Store-submission.zip** contains unsigned x64/ARM64 MSIX
  inputs for Partner Center. It is for the publisher, not an app installer.
  Use the Microsoft Store listing for a Store-signed installation. Publishing
  the app in the Store does not sign these separate GitHub files.

Installer users can use **Settings → About → Check for updates**. Installers
preserve cached reminders, queued edits, preferences and saved sign-in. The
installers are unsigned, so Windows SmartScreen may show a warning.

## Compatibility notes

Create and edit tags in Apple Reminders. List creation, rename and deletion remain
unsupported. Unsupported custom repeat rules must be completed on an Apple device.
Repeats created by an earlier test build with the wrong frequency must be changed
to the intended schedule; the app cannot distinguish them from intentional rules.

Use Apple's hosted sign-in or native SMS flow; app-specific passwords do not
replace this service's login. Apple controls verification availability and session
expiry. Review [setup](../getting-started.md), [sign-in options](../authentication.md),
and the [privacy policy](../../PRIVACY.md) before signing in.

## Validation

The feature branch passed 836 account-free backend/authentication/scheduling/layout
checks, 24 updater checks, 8 CI policy checks and x64/ARM64 builds and packaging.
CI tests packaged launch on x64; native ARM64 launch and signed Store upgrades
still require the corresponding devices/distribution. The user confirmed corrected
recurring dates and Apple-device sign-in returning to the native app. Account-free
tests do not establish every live Apple account or device scenario.
